W. S. Braithwaite. All published 1913–1914, so public domain in the US. Text was taken from Gutenberg's proofread edition, not OCR. Selection rules:
- 8–20 lines.
- Very well-known poets left out (Kilmer, Teasdale, Millay, E. A. Robinson, Lindsay, Carman, Le Gallienne, Untermeyer, Aiken).
- Long poems, translations, and poems that run lines over left out.
- Plain and sentimental poems deliberately included, so the screen can meet the at-least-10-below-6 rule for each model.

The "Guess" notes are my own reading before any screen, recorded only to show the pool is skewed weak. They are not used for selection; the screen scores are.

Conversions, matching poems 04–09:
- Indentation dropped and stanza breaks kept.
- `--` changed to `—`.
- Gutenberg's `_italic_` markers removed.
- Curly quotes kept as printed.
